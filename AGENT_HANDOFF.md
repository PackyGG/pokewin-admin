## ⚠️ Gotchas (session-relevant)

- **Dev-server PORT collision across worktrees (2026-06-14)** — multiple parallel worktrees run `next dev`/`next start`, all defaulting to **:3000**. The first to bind wins; a later `npm run dev` silently fails to bind and your Playwright/curl then hits the OTHER worktree's STALE code (you'll see pre-edit labels render despite a clean local diff + fresh `.next`). FIX: render-verify on a unique port (`PORT=3100 npm run dev`) and confirm the :PORT listener's `CommandLine` matches YOUR worktree path before trusting any render. Also: start the dev server via the Bash tool's `run_in_background:true` (a `&`-detached `npm run dev` dies when the tool call returns on Windows).
- **Stale local game DB** — live admin pages throw locally → use fixtures (`src/app/responsive-fixture/*`) or prod; Creator Hub e2e detail tab skips when no `creator` role user in MAIN
