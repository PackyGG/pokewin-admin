## ⚠️ Gotchas (session-relevant)

- **Dev-server PORT collision across worktrees (2026-06-14)** — multiple parallel worktrees run `next dev`/`next start`, all defaulting to **:3000**. The first to bind wins; a later `npm run dev` silently fails to bind and your Playwright/curl then hits the OTHER worktree's STALE code (you'll see pre-edit labels render despite a clean local diff + fresh `.next`).
